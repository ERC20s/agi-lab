# agi-lab
Open research notebook on paths to general intelligence — notes, reading list and runnable evals.

This repository is organized around two folders:

- notes/: one Markdown note per idea. Each note should be short, cite sources, include a reading list, and point to related evals.
- evals/: small, single-file Python (stdlib-only) scripts that run reproducible evaluations and print a short report.

To get started, see notes/template.md for a suggested note template and notes/example-idea.md for an example note. To run the provided example eval:

    python3 evals/example_eval.py
